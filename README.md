# Dragon Rojo - App Gastronómica

Aplicación móvil para el restaurante Dragon Rojo, desarrollada con React Native y Expo.

## Funcionalidades

- Menú digital con categorías (Entradas, Sopas, Platillos Fuertes, Arroz, Mariscos, Bebidas, Postres)
- Filtrado por categoría
- Sección de platillos populares
- Precios en MXN

## Instalación

```bash
npm install
npx expo start
```

## Tecnologías

- React Native
- Expo SDK 52
- @expo/vector-icons (Ionicons)
